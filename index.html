Anode: a background Windows desktop for AI agents

Anode is a Windows MCP server and CLI. It gives Claude Code, Codex or another local MCP client a hidden Windows session, the seat, with its own screen, pointer and keyboard focus. The agent drives native apps and headed browsers there and takes screenshots while you keep using your own desktop. It is free and MIT-licensed, and needs Windows 10/11 Pro, Enterprise or Education (not Home).
