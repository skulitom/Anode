Anode comparisons

We make Anode, a Windows MCP server and CLI that gives an AI agent a hidden Windows session with its own screen, pointer and keyboard focus. These pages compare it with other tools that let an AI agent work on a Windows PC, and show how to run one of them, Windows-MCP, inside Anode. Each page says which numbers we measured and which we read from the other tools' docs and source, and when it was last checked; the repository document says when its facts were read.

Windows desktop automation for AI agents: Anode, BgDesk, Windows-MCP, Desktop Touch MCP, windows-computer-use-mcp and Terminator compared

Checked 24 October 2026 (first published 16 October). Anode and BgDesk run the agent in a separate Windows session (a child session) with its own pointer and keyboard focus. Windows-MCP, Desktop Touch MCP, windows-computer-use-mcp and Terminator act in your own session, and each of the four has click paths that move your real pointer. Ghost, lowlevel-computer-use-mcp and computer-use-plus drive apps with window messages instead, and start them on a hidden desktop in your session. The other tools were read from their docs and source code, not run by us. In Anode's live validation of version 0.11.1, with your real pointer over Anode's hidden viewer, Windows' Remote Desktop control tried 7 times to copy the agent's pointer moves to your pointer, and Anode blocked all 7. The page also compares tools, sign-in, setup and telemetry.

Windows-MCP in the background: run it in Anode's hidden Windows session

Tested 22 October 2026. Windows-MCP 0.8.8, started inside Anode's seat, made 13 tool calls (7 from a script, 6 from Claude Code) that returned without an error and with no USER_CONTROL pause from its control gate, while the pointer on the PC's own desktop never moved and its foreground window never changed. Nobody used the PC during the run, so how the gate behaves while someone works is not yet measured. The page gives the setup steps, the limits, and when to use Windows-MCP's unreleased main branch, a virtual machine or Anode's own server instead.
