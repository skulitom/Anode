# Security policy

## Reporting a vulnerability

Please report a vulnerability privately: open this repository's **Security** tab and choose
**Report a vulnerability** (https://github.com/skulitom/Anode/security/advisories/new). Please don't
open a public issue for it.

## Security model

[docs/SECURITY.md](docs/SECURITY.md) states what `anode setup` changes on your machine, what the seat
is and is not isolated from, and how to stop it.
