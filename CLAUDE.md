# Working with Anode

Read [AGENTS.md](AGENTS.md) for the repository build, verification and session-safety constraints.
Use the `anode` MCP server or the freshly built `dist\anode.exe`; do not use a foreground desktop
controller for seat work. See [docs/DEVELOPMENT-TESTING.md](docs/DEVELOPMENT-TESTING.md) for command jobs,
UI waits and native/browser verification, and [docs/CONNECTING-AGENTS.md](docs/CONNECTING-AGENTS.md)
for registration. Keep user applications running; clean up only your own test jobs and fixtures.
